# Model Training Pipelines

## Purpose
Contains execution scripts, evaluation loops, validation splits, and metric logging used to train the forecasting and classification models.

## Future Components
- `train_classifier.py`: Trains the multi-class attack detection baseline.
- `train_forecaster.py`: Trains the sequence prediction model using cross-entropy and sequence-to-sequence objectives.
- `evaluate.py`: Generates confusion matrices, ROC-AUC curves, Precision-Recall benchmarks, and latency evaluation.
